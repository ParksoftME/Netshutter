# NetShutter — 어디로 새고 있나

내 PC가 **지금 밖으로 무엇을 내보내고 있는지** 한눈에 보여주는 작은 상주 위젯.
"방송 끈 줄 알았는데 트레이의 OBS가 계속 송출 중", "허들 나왔는데 마이크가 안 꺼짐" 같은
사생활 노출 사고를 막기 위한 도구입니다.

> KGNF Games · MIT License · Windows 10/11 (64-bit)

## 무엇을 보여주나

컴팩트한 목록 위젯. 한 줄 = 앱 하나.

```
● OBS        🎙 🖥      6.1M  ⟋⟍⟋
● Slack      🎙         48K   ⎯⎯
● Dropbox    🌐         1.2M  ⟋⟋⟍
```

- **색**: 빨강 = 마이크·영상 송출, 노랑 = 대용량 전송, 회색 = 대기
- **아이콘**: 그 앱이 지금 쓰는 것만 (🎙 마이크 / 🖥 영상·화면 / 🌐 대용량 네트워크)
- **숫자 + 미니 차트**: 현재 업로드 속도와 최근 추이
- 아무것도 안 나가면 아이콘 3개 + "조용함"으로 축소
- **트레이 송출 감지**: 보이는 창 없이 송출 중인 앱은 흰 테두리로 깜빡임
- 위젯은 **화면 캡처/녹화에서 제외**되어 방송 화면에는 찍히지 않음

## 끄기 (줄에 마우스를 올리면)

차트 자리가 토글 버튼으로 바뀝니다.

- **마이크 끄기** — 시스템 녹음 장치를 음소거 (다시 누르면 해제). *윈도우가 앱별 마이크 끄기를
  지원하지 않아 장치 단위로 동작합니다 → 모든 앱의 마이크가 함께 꺼집니다.*
- **네트워크 차단** — 그 앱만 방화벽에서 차단. 앱은 살아 있고 밖으로만 막힘. 다시 누르면 해제.
  (랙 걸린 것처럼 연결이 끊깁니다. 종료가 아니라 혈관을 막는 방식)

## 어떻게 감지하나 (정직하게)

| 항목 | 방법 | 확실도 |
|---|---|---|
| 마이크·카메라 사용 앱 | 윈도우 프라이버시 기록(ConsentStore) | 확실 |
| 앱별 송수신 속도 | Kernel-Network ETW (활동 중에만 켜짐) | 확실 (관리자 권한 시) |
| 영상 송출 여부 | 1Mbps↑ 지속 업로드 또는 카메라 사용 | 추정 |
| 트레이 송출 | 송출 중 + 보이는 창 없음 | 확실 |
| 화면/카메라 구분 | 네트워크만으론 불가 → "영상"으로 통합 표시 | — |

다른 앱의 메모리나 통신 내용은 건드리지 않습니다. 윈도우가 공개한 자체 기록과 계측만 읽습니다.

## 리소스

- 유휴 시 ETW 세션을 꺼서 부하 ≈ 0 (1초 폴링만)
- 트래픽·마이크 활동이 감지될 때만 앱별 추적 가동
- 단일 실행파일, 런타임 설치 불필요, 메모리 수 MB

## 관리자 권한

앱별 송수신량(ETW)과 방화벽 차단에 관리자 권한이 필요해 실행 시 UAC가 뜹니다.
거부해도 동작은 하지만 앱별 특정·차단 기능은 비활성화됩니다.
매번 UAC 없이 쓰려면 우클릭 메뉴 → **윈도우 시작 시 실행** (작업 스케줄러 등록).

## 빌드

MSYS2(UCRT64)에서 `build.bat` 실행, 또는:

```
g++ -std=c++17 -municode -O2 -s -mwindows -static -static-libgcc -static-libstdc++ \
  -o NetShutter.exe src/main.cpp src/netmeter.res.o \
  -lgdiplus -lole32 -loleaut32 -luuid -liphlpapi -ldwmapi -lshell32 -ladvapi32 \
  -lversion -lntdll -lws2_32 -lgdi32 -luser32
```
